# Gerador-de-senhas

Aplicação web desenvolvida em javascript, focada na geração de senhas aleatórias com interface moderna, profissional e inspirada em sistemas de cibersegurança.

## Funcionalidade:
- Geração de senhas aleatórias
- Copia senha com um clique
- Feedback visual com notificação animada
- Animações suaves

### Tecnologias
- HTML5
- CSS
- JS
